# Tools & Methodology

## Approach

I apply a structured investigative methodology to all technical and analytical work:

1. Define the problem  
2. Identify available data sources  
3. Acquire and preserve data  
4. Analyze artifacts and evidence  
5. Correlate findings  
6. Document results
